# IBM Plex Mono arrow glyph

`ibm-plex-mono-arrow-400.ttf` and `ibm-plex-mono-arrow-500.ttf` contain the
Regular (400) and Medium (500) U+2197 north-east arrow. The Latin subsets omit
this glyph, so `src/style.css` loads these local faces only for U+2197.
Arrow markup also uses U+FE0E to request text presentation.

Source: [Google Fonts subset](https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500&text=%E2%86%97&display=block).
